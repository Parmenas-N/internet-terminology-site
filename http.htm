Hypertext Transfer Protocol (HTTP)

📖 Definition HTTP is the set of rules for transferring web pages between a browser and a server. It defines request methods (GET, POST) and response status codes (200 OK, 404 Not Found).
🔧 Role in Technology HTTP is the foundation of data communication on the World Wide Web.

How It Works

The client sends an HTTP request (e.g., GET /page.html). The server processes it and sends back an HTTP response with a status code and the requested data.

Key Features

  • Request-response model
  • Stateless protocol (each request is independent)
  • Multiple methods (GET, POST, PUT, DELETE)
  • Status codes indicate success or failure
💡 Real-World Example
When you submit a login form, your browser sends a POST request with your username and password.
